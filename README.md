# Register-form

A simple registration form built using HTML, Tailwind CSS, and JavaScript.

Features
Name, Email, and Password fields
Real-time form validation
Error messages for invalid inputs
Password must contain at least 6 characters
Submit button is disabled until all fields are valid
Clean and responsive design using Tailwind CSS

Technologies Used
HTML
Tailwind CSS (CDN)
JavaScript

How to Run
Download or clone this repository.
Open index.html in your browser.
Fill in the form and test the validation.

This project helped me practice form validation and basic JavaScript DOM manipulation.
